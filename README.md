**Solmaris** — an original 2D top-down open-world crime game in vanilla JavaScript and canvas, with zero dependencies and zero external assets. Play as Marlo Reyes, a dock courier in the sun-soaked port city of Puerto Solmaris: walk and drive a living grid city with traffic and pedestrian AI, steal cars, outrun a wanted-level police system with real pursuit and arrest, fight on foot, and work a three-chapter story of dock jobs for Nadia — plus a repair yard, a supply shop, a HUD with minimap, localStorage saves, and fully synthesized WebAudio sound.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```

(Node 22. `node main.ts` with `MAKEFUN_OUTPUT_DIR` set builds the submission output: the game, the screenshots and dossier.json.)
